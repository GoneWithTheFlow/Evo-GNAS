# Evo-GNAS: Evolutionary Graph Neural Architecture Search for Quadratic Unconstrained Binary Optimization
## Overview
In this paper, we propose Evo-GNAS. The core idea of our method is to automatically generate effective Graph Neural Networks (GNNs) for Quadratic Unconstrained Binary Optimization (QUBO) using graph neural architecture search with evolutionary algorithms.
